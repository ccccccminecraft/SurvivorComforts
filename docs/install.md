# 導入（一人で遊ぶ）

- [README に戻る](../README.md)
- サーバーで使うときは [install-server.md](install-server.md) を見てください

[Steam ワークショップのページ](https://steamcommunity.com/sharedfiles/filedetails/?id=3829529741)でサブスクライブし、メインメニュー →「MOD」で **Survivor Comforts** を有効にします。

- 限定公開（未掲載）なので、ワークショップの検索には出ません。上の URL から開いてください
- Build 42.21 以降が必要です
- 機能ごとの ON/OFF は、「オプション」→「MOD」→「Survivor Comforts」で切り替えます
