# 機能

Survivor Comforts に入っている機能です。機能ごとに「オプション」→「MOD」→「Survivor Comforts」で ON/OFF できます。

- [README に戻る](../README.md)

| ID | 機能 | 内容 |
| --- | --- | --- |
| F02 | インベントリ検索 | インベントリと周りの容器の一覧の検索欄で、名前で一覧を絞り込みます。合うアイテムが上にまとまり、ほかは暗く表示されます（オプションで隠すこともできます）。ひらがなとカタカナは区別せず、英語名（`hammer` など）でも見つかります。検索中の「すべて取る」「すべて移す」は、合うアイテムだけを移します。itsu07 さんの [Inventory Search](https://github.com/itsu07/pz-inventory-search) を元にしています |
| F03 | 材料のレシピをたどる | 製作・建築の画面で材料を右クリック →「レシピを見る」で、その材料を作れるレシピに絞り込みます。検索欄の左の「戻る」で、たどる前の表示に戻れます |
| F04 | 読書の残り時間 | 本を読んでいる間、読み終わるまでの時間（ゲーム内はオレンジ、現実は緑）をキャラクターの足元に表示します |
| F06 | ウィッシュリスト | 欲しいアイテムを登録すると、インベントリや周りの容器で色付きで表示されます。自分だけのリストと、サーバー全員で共有する「みんなのリスト」があります。製作・建築の画面からも追加できます |
| F07 | 料理の食材をまとめる | スープやサラダに食材を加えるメニューで、同じ食材を1行にまとめ、残りが少ないものから使います |
| F08 | スキルウィンドウ | スキルの一覧を、大きさを変えられる独立したウィンドウで表示します。画面左のボタンか、オプションで決めたキー（初期値はキーなし）で開きます |
| F09 | プレイヤー一覧 | サーバーにオンラインの人と、7日以内に来ていたオフラインの人（「3時間前」のように最終ログイン付き）を一覧で表示します。画面左のボタンで開きます。マルチプレイのみ |
| F16 | レシピ検索 | アイテムや建築物の名前で検索して、作り方（製作・建築・料理）と直し方、材料・道具としての使い道を、ウィンドウで調べます。材料の名前を押すと、そのアイテムに移り、「[+]」を押すと、その材料の作り方をその場でたどれます。「作成可」で、今の持ち物で作れるものに絞れます。右クリックで、本体の製作・建築の画面をそのアイテムやレシピで開いたり、ウィッシュリストに追加したりできます。ゲームが読み込んだレシピを使うので、MOD のレシピも出ます。画面左のボタンか、オプションで決めたキーで開きます。itsu07 さんの HTML のアプリ「PZ レシピ検索」を元に、Lua で作り直しています（使い方は [アイテム検索の使い方](item-finder.md)） |
| F15 | ほかの人のスキルを見る | プレイヤー一覧でオンラインの人をクリックすると、その人のスキルのレベルをウィンドウで表示します。スキルはサーバーで読むので、ごまかせません。マルチプレイのみ。itsu07 さんの [Skill Viewer](https://github.com/itsu07/SkillViewer) を元にしています |
| F17 | スキルのトップ | スキルごとに、サーバーにオンラインの人の中で一番レベルが高い人と、そのレベルをウィンドウで表示します。同じレベルの人が複数いれば全員を出します。画面左のボタンか、オプションで決めたキーで開きます。マルチプレイのみ |
| F10 | PvP の切り替えボタンを隠す | 画面左のドクロのボタンを隠し、PvP を常にオフにします |
| F12 | アイテムからレシピを見る | アイテムを右クリック →「レシピを見る」で、そのアイテムを作れるレシピに絞り込んだ製作の画面を開きます |
| F13 | ユーザーパネルのボタンを隠す | 画面左のユーザーパネル（派閥・セーフハウスなど）のボタンを隠し、下のボタンを詰めます。管理者には常に表示します。隠している間は、パネルの中の画面（派閥、チケットなど）も開けません。使うときはオプションで外します |
| F14 | 英語名でも検索する | 日本語でプレイしていても、製作・建築の画面の検索で英語名（`plank` など）でもレシピが見つかります。オプションで、英語名を含めるかを選べます |

予定している機能や、作らないことにした機能は [features.md](features.md) にまとめています。機能ごとの詳しい仕様は [features/](features/) にあります。
