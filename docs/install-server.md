# 導入（サーバー）

- [README に戻る](../README.md)
- 一人で遊ぶときは [install.md](install.md) を見てください

[Steam ワークショップ](https://steamcommunity.com/sharedfiles/filedetails/?id=3829529741)に限定公開（未掲載）でアップロードしています。検索には出ないので、この URL から開いてください。

サーバーの設定（`<サーバー名>.ini`）に次の2つを追加します。ほかの MOD がある場合は `;` で区切って並べます。

```
WorkshopItems=3829529741
Mods=SurvivorComforts
```

- ゲーム内のサーバー設定の画面の「Steam ワークショップ」「MOD」から選んでも同じです
- サーバー側の処理（みんなのウィッシュリスト、プレイヤー一覧、ほかの人のスキル）も同じ MOD に入っているので、追加の導入作業はありません
- プレイヤーは、サーバーに接続すると自動でダウンロードされます。自分でサブスクライブする必要はありません
- 機能ごとの ON/OFF は、各プレイヤーが自分のオプションで切り替えます
