# アイテム検索の使い方

F16 レシピ検索の、ウィンドウ「アイテム検索」の使い方です。アイテムや建築物の名前で検索して、作り方と使い道を調べます。

- [README に戻る](../README.md)
- [機能の一覧](feature-list.md)
- 今は、アルファ版 Survivor Comforts (Alpha)（[ワークショップ](https://steamcommunity.com/sharedfiles/filedetails/?id=3832140066)）でだけ使えます。安定版にはまだ入っていません
- 「材料の展開」「道具も展開」「持っているものを先に並べる」は、まだアルファ版にも入っていません（開発中の版だけ）

## 開き方

- 画面左のアイコンの列にある、虫眼鏡のボタンを押します。もう一度押すと閉じます
- オプションでキーを決めておくと、キーでも開けます（初めはキーなし）
- ウィンドウの大きさは、右下の角で変えられます。位置と大きさは、閉じても覚えています

## 画面の見方

| 場所 | 内容 |
| --- | --- |
| 上 | 検索欄、絞り込み（すべて／製作／建築／作成不可）、「作成可」のチェックボックス |
| 左 | 見つかったアイテムと建築物の一覧 |
| 右 | 選んだアイテムの作り方と使い道。いちばん上に「戻る」「進む」と「道具も展開」 |

## 探す

- 検索欄に名前を入れます。名前の一部だけでも見つかります
  - ひらがなとカタカナは区別しません（「はんまー」でも「ハンマー」が見つかります）
  - 空白で区切ると、全部を含むものに絞り込みます（例：「木 板」）
  - F14（英語名でも検索する）が ON なら、英語名でも見つかります（例：`plank`）
- 検索欄が空のときは、何も出ません（「作成可」にチェックが入っているときは別。下の「今作れるものだけ見る」）
- 対象は、どれかのレシピに出てくるアイテムと、建築物（壁・家具・設備など）です。ゲームが読み込んだレシピを使うので、MOD のレシピも出ます

### 絞り込み

| 選択肢 | 出るもの |
| --- | --- |
| すべて | 全部（アイテムと建築物） |
| 製作 | 製作のレシピで作れるアイテム |
| 建築 | 建築物 |
| 作成不可 | どのレシピでも作れないアイテム（拾う・採る・解体するなどで手に入れるもの） |

## 今作れるものだけ見る（作成可）

- 「作成可」にチェックを入れると、今の持ち物と、周りの容器・床にあるもので作れるアイテムと建てられる建築物が、一覧の上にまとまります。作れないものは、その下に暗く出ます
  - 範囲は、本体の製作の画面と同じです
  - オプション「作成可のとき、作れないものも暗く表示する」を OFF にすると、作れないものは一覧から隠れます
- 絞り込みと組み合わせられます（例：「建築」＋「作成可」で、今建てられる建築物だけ）
- チェックが入っているときは、検索欄が空でも、今作れるものが全部出ます
- 右側でも、今作れないレシピが暗くなります（右側は隠さず、暗くするだけです）
- 持ち物を拾う・捨てる・容器から出す、作業面（机など）のそばに行く・離れると、少しして結果が変わります

## 作り方と使い道（右側）

アイテムを選ぶと、右側に次の順で出ます。

1. アイテムの名前・分類・内部名
2. 作り方：そのアイテムを作るレシピ（開いた状態）
3. 材料として使う：そのアイテムを使ってなくなるレシピ（閉じた状態）
4. 道具として使う：そのアイテムを使ってもなくならないレシピ（閉じた状態）

- レシピの行の「[+]」を押すと開き、「[-]」で閉じます。開くと、材料・道具・完成品と数、条件（スキル、習得が必要か、明かりが必要か、作る場所）が出ます
- レシピの頭の「[製作]」「[建築]」で、製作の画面と建築の画面のどちらで作るかが分かります
- 「ハンマー など5種」のように、どれでもよい材料は1行にまとめています。押すと、なれるアイテムが全部並びます
- 液体の材料は、名前と量だけ出ます

### ほかのアイテムに移る

- 緑の名前を押すと、そのアイテムに移ります
- 「戻る」で前のアイテムに戻り、「進む」で戻る前のアイテムに進みます（ブラウザと同じ動き）。開いたレシピの形も、戻ったときに元のままです
- 履歴は 50 件まで覚えます。ウィンドウを閉じても残ります

### 材料の作り方をその場でたどる（材料の展開）

- 開いたレシピの中で、製作で作れる材料には、名前の前に「[+]」が付きます。「[+]」を押すと、その下に1段内側に、その材料の作り方が出ます
  - 作り方が1つだけのときは、開いた状態で出ます
  - 出てきた材料も、同じように「[+]」で開けます
- 「[+]」ではなく名前を押すと、今までどおりそのアイテムに移ります
- 「作り方」「材料として使う」「道具として使う」のどのレシピの中でも開けます
- 「[+]」が付かないもの：
  - レシピで作れない材料（丸太など）
  - 今見ているアイテム自身
  - 開いた道筋の上に、同じアイテムがもうあるとき（ぐるぐる回らないように）
  - 20 段より深いところ
- 数は1回分です。全体で何個要るかの合計は出しません

### 道具も展開

- 道具（使ってもなくならないもの）は、初めは「[+]」が付きません
- 右側のいちばん上の「道具も展開」にチェックを入れると、道具も材料と同じように開けます
- チェックは、ウィンドウを閉じても覚えています

### 持っているものが先に並ぶ

「作成可」のチェックに関係なく、いつも次の並びです。

- どれでもよい材料（「ハンマー など5種」）を開いたとき：
  1. 今の持ち物と周りの容器・床に、要る数だけあるもの
  2. あるが、数が足りないもの
  3. ないもの
- 「○○ など5種」の○○も、並びの先頭のアイテムになります
- 作り方が複数あるときは、今作れるレシピが先に並びます

## 右クリック

| 右クリックしたもの | 出るもの |
| --- | --- |
| 製作で作れるアイテム（左の一覧・右のアイテムの行） | 「製作する」：本体の製作の画面を、そのアイテムを作るレシピに絞り込んで開く |
| 建築物 | 「建築する」：本体の建築の画面を、そのレシピを選んだ状態で開く |
| 右の「[製作]」「[建築]」のレシピの行 | 「製作する」「建築する」：本体の画面を、そのレシピを選んだ状態で開く |

- どれも、続けてウィッシュリスト（F06）の行が出ます（F06 が ON のとき）。レシピの行では、その完成品について出ます
- このウィンドウから直接は作りません。本体の製作・建築の画面を開いて作ります

## オプション

「オプション」→「MOD」→「Survivor Comforts」の「レシピ」の見出しの下にあります。

| オプション | 内容 | 初め |
| --- | --- | --- |
| レシピ検索 | 機能の ON/OFF | ON |
| 左のアイコンにボタンを表示する | 画面左の虫眼鏡のボタン | ON |
| レシピ検索を開く/閉じる | 開くキー | キーなし |
| 作成可のとき、作れないものも暗く表示する | OFF にすると、作れないものを隠す | ON |

## 知っておくこと

- 「作成可」と「持っているものが先」は、アイテムが増えた・減ったときに調べ直します。液体の量や残りの回数が変わっただけでは、すぐには変わりません（本体の製作の画面と同じ）
- レシピを覚えた・スキルが上がったときは、ウィンドウを開き直すか、「作成可」のチェックを入れ直すと反映します
- 作業台・炉などで作るレシピは、本体では作業台の画面で作るので、「作成可」では作れない扱いになることがあります
- セーブデータには何も書き込みません
- 元になったのは、itsu07 さんの HTML のアプリ「PZ レシピ検索」です。この MOD では Lua で作り直しています
