## 仕様

- 地面を右クリック →「ここを基準点にする」で、そのマスを基準点にする。基準点があるときは「基準点を消す」も出る
  - マスは、右クリックした位置の、キャラクターと同じ階のもの
- 基準点があれば、キャラクターの足元に「基準点まで 23m（北東）」と出す（水色）
  - 距離は、キャラクターの位置から基準点のマスの真ん中までの直線距離。1マスを 1m とし、四捨五入
  - 方角は 8方向（北・北東・東…）。マップの上が北（ゲームの座標で y が小さい方）
  - 0m のときは「基準点にいます」
  - 階が違うときは「・2階上」「・1階下」を後ろに足す（距離は平面だけ）
  - [F04](F04_reading-time.md) の読書の残り時間が出ている間は、その1行下に出す
- 基準点はローカルのプレイヤーごとに1つ。ゲームを終えるまで覚えている（ワールドにもファイルにも書かない）。死んで作り直したら消える
- オプション：「オプション」→「MOD」→「Survivor Comforts」に、見出し「基準点までの距離」を読書の残り時間の次に置き、「有効にする」（初期値ON）。OFF にすると、メニューも表示も出ない
- シングルプレイでもマルチプレイでも使える
- 翻訳キーは `UI_SurvivorComforts_F18_` で始める

今後の案（今回は作らない）：地図の上で2点の距離を測る。基準点を地図に印として出す。基準点をゲームをまたいで覚える

準備：シングルプレイ（`tools\test_debug.ps1`）で十分。階の確認には2階建ての建物を使う。

- [ ] オプション →「MOD」に、読書の残り時間の次に見出し「基準点までの距離」が出て、「有効にする」が ON

- [ ] 2階に上がると「・1階下」が付く
- [ ] 「基準点を消す」で表示が消える
- [ ] 本を読んでいる間は、読書の残り時間の下に出て、重ならない
- [ ] 「有効にする」を OFF にすると、メニューも表示も消える
