# F04 本を読み終えるまでの残り時間

- 状況：✅ 実装済
- コード：`client/SurvivorComforts/F04_ReadingTime.lua`
- 一覧に戻る：[features.md](../features.md)

## 要望

最初の名前：本を読むときの残り時間表示

- 内容： 本を何時間で読み終えられるかを表示する
- 困っている場面・理由： 離席から帰るタイミングがわからん
- 優先度： 低

## 調査結果

- 既存MOD：見つからなかった（読む速さを変えるMODはある：Faster Reading、True Readingなど）
- B42.21のMPで動くか：―
- クライアントだけで実現できるか：できる。読書のアクション（`ISReadABook`）から、残りのページ数と1ページあたりの時間を取得して計算する
- 難しさ：低
- 判定：**自作**

## 仕様

- 案：読書中の進捗バーかツールチップに「残り約○時間（ゲーム内）／約○分（現実）」を表示する。現実の時間は、サーバーの1日の長さの設定から換算する

## 確認項目

準備：スキル本（ページ数の多いもの）と、雑誌・漫画など短いもの。

- [ ] オプション →「MOD」に「読書の残り時間」が表示される
- [ ] 本を読み始めると、キャラクターの足元に「残り --:--（現実 --:--）」が出て、2秒ほどで「残り 01:20（現実 03:05）」のような表示に変わる（ゲーム内は時:分でオレンジ、現実は分:秒で緑。ほかの文字は白）
- [ ] 設定「ゲーム内の時間を表示する」「現実の時間を表示する」で、片方だけの表示（「残り 01:20」を、ゲーム内ならオレンジ、現実なら緑）にできる。両方外すと何も出ない
- [ ] 色分けしても文字が重なったり、中央からずれたりしない
- [ ] 読書中に設定を変えても、すぐ表示が切り替わる
- [ ] 読み進めると残り時間が減っていき、読み終わる・やめると表示が消える
- [ ] 途中から読み直したとき（読みかけの本）も、残りのページ分の時間になる
- [ ] 座る・立つ、ゲームの速度（早送り）を変えると、数秒で現実の時間の表示が追従する
- [ ] 一時停止中は表示がそのまま残り、再開すると続きから更新される
- [ ] 画面をズームしたり、カメラを動かしたりしても、表示がキャラクターの足元についてくる
- [ ] 表示がほかのウィンドウ（インベントリなど）の上にかぶらない
- [ ] 「有効にする」を外すと表示されない
- [ ] マルチプレイ（ローカルで立てたサーバー）でも同じように動く
