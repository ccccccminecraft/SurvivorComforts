# F05 ショートカットキーでマップに印をつける

- 状況：⏸️ 見送り（一旦見送り。[features.md の「実装しない機能」](../features.md#実装しない機能)を参照）
- 一覧に戻る：[features.md](../features.md)

## 要望

最初の名前：ショートカットでマップに目標をつける

- 内容： 1ボタンでマップに印をつける。(ボールペン等は必要)
- 困っている場面・理由: 探索が終わった建物なのかそうでないのかがわからない
- 優先度: 低

## 調査結果

- 既存MOD：Quick'n'Auto Mark（3579410548）：建物に自動で印をつける。ただし、マルチプレイでの動作は未確認
- B42.21のMPで動くか：未確認
- クライアントだけで実現できるか：できる。ゲーム本体のマップの記号は、マルチプレイではゲームが自動でサーバーと同期する（`ISWorldMapSymbols.lua` の `sendModifySymbol` など）。本体と同じ方法で記号を追加すればよい
- 難しさ：低〜中
- 判定：**一旦見送り**（[features.md の「実装しない機能」](../features.md#実装しない機能)へ）。再開するときは、既存MODを試してから自作を判断する（Quick'n'Auto Markは自動で印をつけるので、「1ボタンで手動で印をつける」という希望とは少し違う）

## 仕様（作る場合の案）

- 案：キーを押すと、プレイヤーが今いる建物の位置に、決めた記号を追加する。ペンなど書くものを持っていなければ追加しない（本体の `canWrite()` と同じ判定）
