# F12 インベントリのアイテムからレシピを見る

- 状況：✅ 実装済
- コード：`client/SurvivorComforts/F12_ItemRecipes.lua`、共通の `Recipes.lua`
- 一覧に戻る：[features.md](../features.md)

## 要望

最初の書き出しの後に出た要望

- 内容： インベントリのアイテムを右クリックして「レシピを見る」を選ぶと、そのアイテムを作れるレシピを表示する
- 困っている場面・理由: 手元のアイテムをどう作るのかを調べるのに、制作の画面で検索し直すのが面倒
- 優先度: 中

## 調査結果

- 既存MOD：Context Menu Crafting [B42]（3425516353）は、アイテムを右クリックするとそれを**材料に使う**レシピを出す（逆方向）。作り方を見るものは見つからなかった
- B42.21のMPで動くか：―
- クライアントだけで実現できるか：できる。F06の一覧の「レシピを見る」と同じ方法（本体の制作の画面を開き、材料を Shift+クリックしたときと同じ絞り込みをかける）を使う
- 難しさ：低
- 判定：**自作**

## 仕様

- 範囲：
  - インベントリ・周りの容器のアイテムを右クリックすると「レシピを見る」が出る。選ぶと制作の画面を開き、そのアイテムを作れるレシピに絞り込む
  - 作るレシピがないアイテムには出さない。レシピの一覧（`ScriptManager.instance:getAllCraftRecipes()`）の完成品から、作れるアイテムの一覧を最初に使うときに一度だけ作って判定する
  - 種類の違うアイテムをまとめて選んだときは、種類ごとに「レシピを見る」の下に並べる
  - F06の一覧の「レシピを見る」と処理を共通にする（`Recipes.lua`）。F06の一覧でも、作るレシピがないアイテムは選べない表示にする
  - 建築の画面は対象外。セーブデータには何も書き込まない
  - F03（制作の画面の材料からレシピをたどる）も同じ処理を使う。F03 の「戻る」は、F12 から開いたときにも使える（[F03](F03_recipe-trail.md) を参照）

## 確認項目

- [ ] オプション →「MOD」に「アイテムからレシピを見る」が表示される
- [ ] 作れるアイテム（板、釘、布の切れ端など）を右クリックすると「レシピを見る」が出る
- [ ] 選ぶと制作の画面が開き、そのアイテムを作れるレシピだけに絞り込まれる。制作の画面が開いているときは、そのまま絞り込みが変わる
- [ ] 作るレシピがないアイテム（缶詰、武器の一部など）では「レシピを見る」が出ない
- [ ] 周りの容器・床のアイテムでも出る
- [ ] 種類の違う作れるアイテムをまとめて選ぶと、「レシピを見る」の下にアイテム名が並び、選んだもののレシピに絞り込まれる
- [ ] 初めて右クリックしたときに、目立つ引っかかり（一瞬止まる）がない
- [ ] 「有効にする」を外すと出なくなる。F06の一覧の「レシピを見る」は、F12を外しても使える
- [ ] マルチプレイ（ローカルで立てたサーバー）でも同じように動く
