# F14 制作・建築の画面を英語名でも検索する

- 状況：✅ 実装済
- コード：`client/SurvivorComforts/F14_EnglishSearch.lua`（制作・建築の画面への組み込み）、共通の検索 `client/SurvivorComforts/Search.lua`、英語名の表 `client/SurvivorComforts/EnglishNames.lua`（`tools/make_english_names.ps1` で作る）
- 一覧に戻る：[features.md](../features.md)

## 要望

最初の書き出しの後に出た要望

- 内容： 制作・建築の画面の検索で、日本語名でも英語名でも引っかかるようにする
- 困っている場面・理由: ゲームを日本語にしていると、英語の名前で検索しても出てこない。日本語入力もできない（[F01](F01_japanese-input.md)）ので、日本語名で検索するのも難しい
- 優先度: 中

## 調査結果

- 既存MOD：未調査
- B42.21のMPで動くか：―
- クライアントだけで実現できるか：できる見込み（検索は画面の表示だけの話）
- 本体の仕組み（`ISHandCraftPanel.lua`、`ISBuildPanel.lua`、`BaseCraftingLogic` で確認）：
  - 検索欄の文字は Lua から `logic:filterRecipeList(文字, カテゴリ)` で Java に渡され、絞り込みは Java の中で行われる
  - 比べる相手は、レシピ名は翻訳後の名前（`CraftRecipe.getTranslationName()`）、材料・完成品はアイテムの翻訳後の名前（`Item.getDisplayName()`）。日本語のゲームではどちらも日本語なので、英語では当たらない
  - 先頭の記号で動きが変わる（`!` は完全一致、`@` と `$` は別の検索）。種類（レシピ名・材料・完成品）は Lua から `-@-` を付けて渡している
- 英語名を手に入れる方法：
  - ゲームが読み込むのは今の言語の翻訳だけで、英語の名前を引く関数はない
  - ゲームのファイルを読む Lua の関数（`getGameFilesTextInput`）はあるが、デバッグモードでしか使えない
  - 英語名の元は、ゲームの `media/lua/shared/Translate/EN/Recipes.json`（約1900件。キーはレシピの内部名）と `ItemName.json`（約4900件。キーはアイテムの種類 `Base.Nails` など）
  - 内部名（`SawLogs`、`Base.Nails` など）を単語に分けて英語名の代わりにする方法も調べた。内部名の単語がすべて英語名に含まれるのは、レシピで67%、アイテムで39%だけで、アイテムは特に外れが多い（`308Bullets` → 「7.62x51mm Round」など）
- 絞り込みに英語名を足す方法（案）：
  - 検索の文字に英字が入っているときだけ、Lua で英語名・日本語名の両方と比べて当たったレシピを集め、それを元の一覧として渡してから、本体の絞り込みを空の文字で動かす。覚えたレシピだけ表示・お気に入り・カテゴリなどの本体の絞り込みは、そのまま効く
  - 先頭が記号の検索（`!`、`@`、`$`）と、日本語だけの検索は、今までどおり本体に任せる
- 難しさ：中
- 判定：**自作**（英語名の持ち方を決めてから）

### 決めること：英語名をどこから持ってくるか

| 案 | 内容 | 当たり方 | 気になる点 |
| --- | --- | --- | --- |
| A. 英語名の表をMODに入れる | ゲームの英語の翻訳ファイルから、レシピとアイテムの英語名の表をツールで作り、MODに入れる。ゲームを更新したら作り直す | ゲームの英語版と同じ | ゲームの文章（名前）をMODに入れて配ることになる（翻訳MODと同じ形）。ゲームの更新で新しいレシピが増えたら、作り直すまで英語では出ない |
| B. 内部名を英語名の代わりにする | `SawLogs` →「saw logs」のように、内部名を単語に分けて比べる | レシピは7割ほど、アイテムは4割ほどしか英語名と合わない | 何も配らない。ゲームの更新にもそのままついていく |
| A＋B | 表にあるものは英語名、ないもの（新しく増えたもの）は内部名で比べる | Aとほぼ同じで、更新にも強い | Aと同じ |

→ **A＋B に決定**（2026-10-30）

### 本体の絞り込みとの組み合わせ（追加で確認したこと）
- 絞り込んだ結果の一覧（`logic:getRecipeList()`、`CraftRecipeListNodeCollection`）は Lua から使え、`getAllRecipes()`・`clear()`・`addAll(一覧)` がある。制作の画面（`HandcraftLogic`）と建築の画面（`BuildLogic`）の両方にある
- 元の一覧を取り出す関数（`getRecipes`）はないので、元の一覧を差し替えるのではなく、本体の絞り込みの結果を後から減らす
- Java の中で、並べ替え（`sortRecipeList`）と元の一覧の差し替え（`setRecipes`。周りの容器が変わったときなど）のたびに、覚えている検索の文字で絞り込み直している。そのままだと減らした結果が元に戻るので、これらの後にも減らし直す
- Java の絞り込み（`filterRecipeList(文字, カテゴリ, 作り直す, プレイヤー)`）は、文字とカテゴリが前回と同じだと何もしない。そのままだと前回減らした結果をさらに減らしてしまうので、3つめの引数を `true`（同じでも作り直す）にして呼ぶ
- 画面の一覧は、Java が絞り込みの途中で送るイベント（`onUpdateRecipeList`）で作られる。減らすのはその後なので、減らした後にパネルの `onUpdateRecipeList()` を呼んで、画面の一覧を作り直す

## 仕様

- オプション「英語名でも検索する」（この機能の「有効にする」。初期値ON）で、英語名での検索を含めるかどうかを選ぶ。この MOD の検索すべてに効く（今は制作・建築の画面。F02 のインベントリの検索を作ったら、そちらにも効く）。ゲームの言語が英語のときは何もしない（本体の検索で英語が当たるため）
- 検索の決まり（語の区切り方、比べる名前、合うかどうか）は、共通の `Search.lua` にまとめ、F02 のインベントリの検索でも同じものを使う（2026-10-30 決定）
  - `SurvivorComforts.search.useEnglish()`：英語名での検索を含めるか（上のオプションがONで、ゲームの言語が英語でない）
  - `SurvivorComforts.search.parse(文字)`：検索の文字を、小文字にして空白で区切った語の一覧にする
  - `SurvivorComforts.search.hasLatin(文字)`：英字が入っているか
  - `SurvivorComforts.search.itemText(アイテムの種類, 今の言語の名前)` / `recipeText(レシピ)`：比べる名前（英語名・内部名の単語・今の言語の名前をつなげたもの。英語名での検索を含めないときは今の言語の名前だけ）。一度作った名前は覚えておく。最後の引数に `useEnglish()` の結果を渡せる。検索1回で何千ものレシピやアイテムを比べるので、呼ぶ側は検索の初めに1回だけ判定して、それを渡す（2026-10-31、点検の R2-2）。渡さないときは毎回判定する
  - `SurvivorComforts.search.matches(名前, 語の一覧)`：すべての語が入っているか
  - 制作・建築の画面への組み込み（本体の絞り込みの後で減らす、並べ替えの後にやり直す）は F14 だけのもので、`F14_EnglishSearch.lua` に置く
- 対象は、制作の画面（`ISHandCraftPanel`）と建築の画面（`ISBuildPanel`）の検索欄。作業台など別の制作の画面は対象外
- 動く条件：検索の文字に英字（A〜Z）が入っていて、先頭が記号（`!`、`@`、`$`）でないとき。それ以外（日本語だけの検索、記号の検索、空の検索）は、今までどおり本体に任せる
- 動き
  1. 本体の絞り込みを空の文字で動かす（覚えたレシピだけ・お気に入り・カテゴリなどの絞り込みは、本体のものがそのまま効く）
  2. その結果のレシピのうち、検索の文字に合うものだけを残す
  3. 本体の並べ替え・一覧の差し替えの後にも、2をやり直す
- 合うかどうか：検索の文字を空白で区切り、すべての語が、次の名前をつなげた文字のどこかに入っていれば合う（大文字・小文字は区別しない）
  - 英語名（英語名の表にあるとき）
  - 内部名を単語に分けたもの（`SawLogs` →「saw logs」、`Base.Nails` →「nails」。表にない新しいものもこれで当たる）
  - 今の言語の名前（日本語名。英字と日本語を混ぜた検索もできる）
- 何と比べるかは、本体の検索の種類に合わせる
  - レシピ名（初期値）：レシピの名前
  - 材料：材料に使えるアイテムの名前
  - 完成品：完成品のアイテムの名前
- 英語名の表（`EnglishNames.lua`）
  - ゲームの `media/lua/shared/Translate/EN/Recipes.json`（レシピ。キーはレシピの内部名）と `ItemName.json`（アイテム。キーはアイテムの種類）から、`tools/make_english_names.ps1` で作る。手で直さない
  - ゲームを更新したら、ツールを実行し直して、増えた・消えた・変わった名前を確かめてからコミットする（手順は [dev-guide.md の「ゲームを更新したとき」](../dev-guide.md#ゲームを更新したとき)）
- セーブデータには何も書き込まない

## 確認項目

準備：ゲームの言語を日本語にしておく。

- [ ] オプション →「MOD」に「英語名でも検索する」が、「材料のレシピをたどる」の下に表示される（初期値ON）
- [ ] 制作の画面の検索欄に英語（例：`plank`、`saw logs`）を入れると、そのレシピが出る。日本語名で検索したときと同じものも出る
- [ ] 大文字・小文字を区別しない（`Plank` でも `plank` でも出る）。空白で区切った語は、全部入っているものだけ出る
- [ ] 検索の種類を「材料」「完成品」にすると、英語のアイテム名（例：`nails`、`hammer`）でも、それを使う・作るレシピが出る
- [ ] 日本語だけの検索、`!` で始まる検索（材料の Shift+クリック、「レシピを見る」の絞り込み）は今までどおり動く
- [ ] 「すべてのレシピを表示」・カテゴリ・お気に入りの絞り込みが、英語の検索でも効く
- [ ] 英語で検索したまま、並べ替えを変えたり、周りの容器を開け閉めしたりしても、検索の結果が全部のレシピに戻らない
- [ ] 建築の画面でも、英語で検索できる
- [ ] 「有効にする」を外すと、英語では出なくなる（本体のまま）

- [ ] 文字を打つたびに、目立つ引っかかりがない
