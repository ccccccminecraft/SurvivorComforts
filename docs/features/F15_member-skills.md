### 受け取ったコード（2026-11-01）

- リポジトリ：`itsu07/SkillViewer`。別の MOD「Skill Viewer」（MOD ID `SkillViewer`）として作られている。Lua 4ファイル（約290行）、翻訳（日本語・英語）、テスト用のサーバーを起動するスクリプト
- ライセンスのファイルがない。MIT で同梱してよいと、作者に確かめた（2026-11-01。著作権の表示は itsu07）
- 動き
  - キー（初期値 F7。独自の Mod Options で変えられる）で、画面の中央にウィンドウを開く。大きさは変えられず、位置も覚えない
  - 左に、オンラインのプレイヤーの一覧（「一覧を更新」で取り直す）。名前は表示名（`displayNames`）を出す
  - 右に、選んだプレイヤーのスキル。本体のスキルの画面と同じ順（パッシブが先、ほかはカテゴリ名の順、カテゴリの中はスキル名の順）で、Lv0〜10 を四角の列と数字で出す
  - シングルプレイでは通信せず、自分のスキルだけを出す
- 仕組み
  - オンラインのプレイヤーの一覧は、本体のユーザー一覧と同じ `scoreboardUpdate()` → `OnScoreboardUpdate`（[F09](F09_player-list.md) と同じ）
  - スキルは、サーバーで読む。画面側が「このユーザーのスキルをください」と送ると、サーバーがそのプレイヤーのスキル（`getPerkLevel`）を読んで、頼んだ人にだけ返す。各自の申告ではないので、ごまかせない
  - サーバー側の安全弁：1人が頼めるのは 0.5 秒に1回まで（独自の作り）
  - ワールドには何も書き込まない
- この MOD と比べて
  - 通信は、独自のコマンド名（`SkillViewer`）で直接やり取りしている。この MOD の共通のやり取り（`Commands.lua`・`ServerCommands.lua`。回数の制限は1人1秒5回まで）に置き換えられる
  - プレイヤーの一覧の取り方は F09 と同じ。F09 は名前にユーザー名を使っている（死んで作り直しても変わらないため）
  - ウィンドウは、R1-3 の共通のウィンドウ（`Window.lua`。位置と大きさを覚える、画面左のボタン、開閉キー）に乗せられる
  - スキルの表示は、F08（自分のスキル。本体のスキルの画面をそのまま使う）とは別の作り。ほかのプレイヤーのスキルはサーバーから届いた数字しかないので、本体の画面は使えない
  - グローバル変数（`SkillViewer`、`SkillViewerWindow`）、独自の翻訳キー（`UI_SkillViewer_`）、`safeCall` なし。この MOD の決まりに合わせて直す

## 仕様

受け取ったコードを、この MOD の1機能として取り込む（2026-11-01 決定）。

- 開き方：[F09](F09_player-list.md) のプレイヤー一覧で、オンラインの人をクリックすると、その人のスキルのウィンドウが開く
  - プレイヤーの一覧が2つにならず、画面左のボタンも増えない。元のコードのウィンドウの左側（プレイヤーの一覧と「一覧を更新」）と、F7 のキーは使わない
  - オフラインの人はクリックしても何も開かない（サーバーがスキルを読めないため）
  - 開いたまま別の人をクリックすると、同じウィンドウがその人の表示に変わる
  - F09 と同じく、マルチプレイのみ。シングルプレイでは F09 の一覧が出ないので、F15 も出ない（自分のスキルは [F08](F08_skills-window.md) で見られる）
- オプション：「オプション」→「MOD」→「Survivor Comforts」の「ほかの人のスキルを見る」の「有効にする」（初期値ON）。OFF にすると、F09 の一覧をクリックしても開かない
- ウィンドウ：共通のウィンドウ（`Window.lua`）に乗せる。大きさを変えられ、位置と大きさを覚える。タイトルは「（ユーザー名）のスキル」
  - 中身は元のコードのまま：本体のスキルの画面と同じ順（パッシブが先、ほかはカテゴリ名の順、カテゴリの中はスキル名の順）で、Lv0〜10 を四角の列と数字で出す
  - 開いたとき（別の人に変わったときも）に、サーバーに聞く。届くまでは「取得中…」、その人がいなくなっていれば「データがありません」
- 名前：ユーザー名を使う（F09 と同じ。死んで作り直しても変わらないため）。サーバーで探すときも、F09 と同じプレイヤー名の取り方（`PlayerName.lua`）を使う
- サーバー側：元のコードのとおり、サーバーで、その人のスキルを読んで、頼んだ人にだけ返す。やり取りは、この MOD の共通のやり取り（`Commands.lua`・`ServerCommands.lua`）にする。回数の制限も共通のもの（1人1秒5回まで）にし、元のコードの独自の制限（0.5秒に1回）は外す
- スキルを集める処理（すべてのスキルを順に見る、レベルを集める）は、画面側とサーバー側の両方で使うので、共通の `shared/SurvivorComforts/Skills.lua` に置く
- この MOD の決まりに合わせる：グローバル変数を作らない、追加した処理は `safeCall` で囲む、翻訳キーは `UI_SurvivorComforts_F15_` で始める
- ワールドには何も書き込まない
- 誰でも、オンラインのほかの人のスキルを見られる（元のコードのまま。身内のサーバーで使うため、管理者だけに絞らない）
- クレジット：機能の一覧（`docs/feature-list.md`）と README の「ライセンス」に、元の MOD と作者を書く。`LICENSE` の作者の著作権表示（F02 と同じ itsu07）の対象に F15 を足す

## 確認項目

準備：テスト用のサーバーとゲーム2つ（[dev-guide.md の「1台で複数人を試す」](../dev-guide.md#1台で複数人を試す)）。2人目で、いくつかのスキルのレベルを上げておく（デバッグモードなら、デバッグのメニューで上げられる）。

- [ ] オプション →「MOD」の中項目「プレイヤー一覧」の最後に、「ほかの人のスキルを見る」が表示される（初期値ON）
- [ ] F09 のプレイヤー一覧で、オンラインのもう1人をクリックすると、「（ユーザー名）のスキル」のウィンドウが開き、その人のスキルが出る。2人目で上げたレベルと合っている
- [ ] 自分をクリックすると、自分のスキルが出る
- [ ] 開いたまま別の人をクリックすると、その人の表示に変わる
- [ ] オフラインの人をクリックしても、何も開かない
- [ ] ウィンドウの大きさを変えられる。閉じて開き直すと、同じ位置と大きさで開く
- [ ] 「有効にする」を OFF にすると、クリックしても開かない
- [ ] サーバーのログ（`server-console.txt`）と `console.txt` に、`[SurvivorComforts] F15` のエラーが出ていない
