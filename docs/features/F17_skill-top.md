- 困っている場面・理由：誰に何を任せるか（料理、大工、医療など）を決めるとき、F15 で1人ずつ見て比べるのが手間
- 優先度：

## 調査結果

- 既存MOD：未調査
- クライアントだけで実現できるか：できない。ほかの人のスキルは、サーバーでしか読めない（F15 と同じ）。サーバー側の処理を足す
  - F15 の `skillsRequest` を人数分送ると、共通の回数の制限（1人1秒5回まで）にかかる。オンラインの全員のスキルを1回で返す、別のコマンドにする
  - 一番を決めるのは画面側でする（サーバーの処理を最小にし、テストもしやすい）
- ワールドに書き込むか：書き込まない。そのため、オフラインの人は数えられない（F09 の最終ログインのようにスキルを保存すれば数えられるが、方針の例外を増やすことになるので、しない）
- 難しさ：低〜中。F15 のスキルの一覧と、F09 の「開いている間は1分ごとに聞き直す」を使い回せる
- 判定：**自作**

## 仕様

- 開き方：F09 のプレイヤー一覧のウィンドウの上に、タブ「プレイヤー」「スキルのトップ」を付け（本体の `ISTabPanel`）、「スキルのトップ」のタブで見る。F17 のウィンドウ、画面左のボタン、キーはない
  - 初めは独立したウィンドウと王冠のボタンにしていたが、画面左のボタンが増えすぎるので、2026-11-07 に itsu07 さんと話してタブにした。そのため **F09 の画面に手を入れている**（F17 が OFF なら、タブは出ず、今までどおりの一覧だけ）
  - F17 を ON/OFF すると、開いているウィンドウもすぐにタブが付いたり消えたりする
- マルチプレイのみ（F09・F15 と同じ）。シングルプレイでは F09 自体が出ない
- オプション：「オプション」→「MOD」→「Survivor Comforts」の F09・F15 の見出しの中に、「スキルのトップ」の 1つ（初期値ON）
- 中身
  - 本体のスキルの画面と同じ順（パッシブが先、ほかはカテゴリ名の順、カテゴリの中はスキル名の順。F15 と同じ並びで、`Skills.lua` の `skillGroups` を共通で使う）
  - 1行に、スキル名、一番高いレベル、その人のユーザー名
  - 同じレベルの人が複数いれば、全員を「, 」区切りで出す（大文字・小文字を区別しない名前の順）
  - 全員が Lv0 のスキルは、レベルの代わりに「-」を出し、名前は出さない
  - 人数は「プレイヤー」のタブの「オンライン（N人）」で見る（タブにはタイトルがない）
  - 届くまでは「取得中…」、答えに1人もいなければ「データがありません」
- 聞くとき：タブを開いたとき（5秒以内に開き直したときは聞かない）、タブを開いている間は1分ごと（F09 と同じ間隔）
- 名前：ユーザー名（F09・F15 と同じ。`PlayerName.lua`）
- サーバー側：`skillTopRequest` を受けると、オンラインの全員のスキル（`collectSkills`）を `{ players = { [ユーザー名] = { [スキルのid] = レベル } } }` で、頼んだ人にだけ返す。回数の制限は共通のもの（`F17` の分として1人1秒5回まで）
- この MOD の決まりに合わせる：グローバル変数は一覧のクラスだけ（F09 には `SurvivorComforts.skillTop` で渡す）、`safeCall` で囲む（共通の仕組みが囲む）、翻訳キーは `UI_SurvivorComforts_F17_` で始める
- ワールドには何も書き込まない
- 誰でも見られる（F15 と同じ）

## 確認項目

準備：テスト用のサーバーとゲーム2つ（[dev-guide.md の「1台で複数人を試す」](../dev-guide.md#1台で複数人を試す)）。2人で、いくつかのスキルを違うレベルにしておく。1つは2人とも同じレベルにする（デバッグモードなら、デバッグのメニューで上げられる）。

- [ ] オプション →「MOD」の F09・F15 の見出しの中に「スキルのトップ」が出て、ON
- [ ] 画面左に F17 のボタンはない。プレイヤー一覧を開くと、上にタブ「プレイヤー」「スキルのトップ」があり、「プレイヤー」が選ばれている
- [ ] 「プレイヤー」のタブは今までどおり（オンラインの人をクリックすると F15 が開く）
- [ ] 「スキルのトップ」のタブを押すと、「取得中…」の後に一覧が出る

- [ ] ウィンドウの大きさを変えると、どちらのタブの中身もウィンドウに合わせて広がる
- [ ] 「スキルのトップ」を OFF にすると、開いているプレイヤー一覧からもタブが消え、今までどおりの一覧になる。ON に戻すとタブが付く
