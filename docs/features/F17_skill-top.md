# F17 スキルのトップ

- 状況：⬜ 未実装（コードとテストは書いた。ゲームでの確認はまだ。2026-11-06）
- コード：`client/SurvivorComforts/F17_SkillTop.lua`、`server/SurvivorComforts/F17_SkillTop.lua`、共通の `shared/SurvivorComforts/Skills.lua`（スキルを集める処理と並び順。F15 と共通）
- 一覧に戻る：[features.md](../features.md)

## 要望

- 内容：全スキルについて、一番レベルが高い人とそのレベルを出す
- 困っている場面・理由：誰に何を任せるか（料理、大工、医療など）を決めるとき、F15 で1人ずつ見て比べるのが手間
- 優先度：

## 調査結果

- 既存MOD：未調査
- クライアントだけで実現できるか：できない。ほかの人のスキルは、サーバーでしか読めない（F15 と同じ）。サーバー側の処理を足す
  - F15 の `skillsRequest` を人数分送ると、共通の回数の制限（1人1秒5回まで）にかかる。オンラインの全員のスキルを1回で返す、別のコマンドにする
  - 一番を決めるのは画面側でする（サーバーの処理を最小にし、テストもしやすい）
- ワールドに書き込むか：書き込まない。そのため、オフラインの人は数えられない（F09 の最終ログインのようにスキルを保存すれば数えられるが、方針の例外を増やすことになるので、しない）
- 難しさ：低〜中。F15 のスキルの一覧と、F09 の「開いている間は1分ごとに聞き直す」を使い回せる
- 判定：**自作**

## 仕様

- 開き方：画面左のボタン（王冠のアイコン。F16 の下）か、オプションで決めたキー（初期値はキーなし）。F08・F09 と同じく、共通のウィンドウ（`Window.lua`）に乗せる。大きさを変えられ、位置と大きさを覚える
  - F09 のプレイヤー一覧から開く形も考えたが、F09 のウィンドウにボタンを足す必要があり、F15 の「行をクリック」とも混ざるので、独立したボタンにした（変えるなら相談）
- マルチプレイのみ（F09・F15 と同じ）。シングルプレイではボタンが出ない
- オプション：「オプション」→「MOD」→「Survivor Comforts」に、見出し「スキルのトップ」を F09・F15 の次に置く。「有効にする」（初期値ON）、「左のアイコンにボタンを表示する」（初期値ON）、開閉のキー
- 中身
  - 本体のスキルの画面と同じ順（パッシブが先、ほかはカテゴリ名の順、カテゴリの中はスキル名の順。F15 と同じ並びで、`Skills.lua` の `skillGroups` を共通で使う）
  - 1行に、スキル名、一番高いレベル、その人のユーザー名
  - 同じレベルの人が複数いれば、全員を「, 」区切りで出す（大文字・小文字を区別しない名前の順）
  - 全員が Lv0 のスキルは、レベルの代わりに「-」を出し、名前は出さない
  - タイトルは「スキルのトップ（オンライン N人）」
  - 届くまでは「取得中…」、答えに1人もいなければ「データがありません」
- 聞くとき：開いたとき、開いている間は1分ごと（F09 と同じ間隔）
- 名前：ユーザー名（F09・F15 と同じ。`PlayerName.lua`）
- サーバー側：`skillTopRequest` を受けると、オンラインの全員のスキル（`collectSkills`）を `{ players = { [ユーザー名] = { [スキルのid] = レベル } } }` で、頼んだ人にだけ返す。回数の制限は共通のもの（`F17` の分として1人1秒5回まで）
- この MOD の決まりに合わせる：グローバル変数はウィンドウのクラスだけ、`safeCall` で囲む（共通の仕組みが囲む）、翻訳キーは `UI_SurvivorComforts_F17_` で始める
- ワールドには何も書き込まない
- 誰でも見られる（F15 と同じ）

## 確認項目

準備：テスト用のサーバーとゲーム2つ（[dev-guide.md の「1台で複数人を試す」](../dev-guide.md#1台で複数人を試す)）。2人で、いくつかのスキルを違うレベルにしておく。1つは2人とも同じレベルにする（デバッグモードなら、デバッグのメニューで上げられる）。

- [ ] オプション →「MOD」に、F09・F15 の次に見出し「スキルのトップ」が出て、「有効にする」「左のアイコンにボタンを表示する」が ON、キーは空
- [ ] 画面左に王冠のボタンが出る（F16 の虫眼鏡の下）。押すとウィンドウが開き、もう一度押すと閉じる
- [ ] タイトルが「スキルのトップ（オンライン 2人）」になる
- [ ] スキルごとに、高い方の人の名前とレベルが出る。同じレベルのスキルでは2人とも出る。2人とも Lv0 のスキルは「-」
- [ ] 並びが F15 のウィンドウと同じ
- [ ] 開いたまま片方のレベルを上げると、1分以内に表示が変わる
- [ ] 1人が抜けると、1分以内にその人が消え、タイトルが「オンライン 1人」になる
- [ ] ウィンドウの大きさを変えられる。閉じて開き直すと、同じ位置と大きさで開く
- [ ] 「有効にする」を OFF にするとボタンが消え、キーでも開かない
- [ ] シングルプレイではボタンが出ない
- [ ] サーバーのログ（`server-console.txt`）と `console.txt` に、`[SurvivorComforts] F17` のエラーが出ていない
