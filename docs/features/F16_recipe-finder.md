# F16 レシピ検索

- 状況：⬜ 未実装（段階 1 を作成し、2026-11-02 にデバッグモードのシングルプレイで確認した。未公開）
- コード：`client/SurvivorComforts/F16_RecipeFinder.lua`（ウィンドウ）、`client/SurvivorComforts/RecipeIndex.lua`（索引）
- 一覧に戻る：[features.md](../features.md)

## 要望

- 内容：アイテム名で検索して、そのアイテムの作り方（製作・建築・料理・修理）と使い道（何の材料・道具になるか）を、ゲームの中のウィンドウで調べられるようにする。材料の作り方も順にたどれるようにする
- 困っている場面・理由：本体の製作の画面は「今作れるか」を見る画面で、「このアイテムは何に使えるか」「材料をどこから作るか」をまとめて調べにくい。ゲームの外の HTML のツールでは調べられるが、ゲームを離れる必要があり、バニラ（MOD なし）の決まった版のデータしか載らない
- 元になるもの：itsu07 さんの HTML のアプリ「PZ レシピ検索」（`pz_recipe_finder.html`、42.21.0 用）。画面の作りと表示する内容を参考にし、コードは Lua で作り直す
- 優先度：

## 調査結果

- 既存MOD：Context Menu Crafting [B42]（3425516353）は、アイテムの右クリックで、それを材料に使うレシピを出す（F12 の調査を参照）。作り方・使い道・材料の展開をまとめて調べる画面は見つかっていない
- B42.21のMPで動くか：―
- クライアントだけで実現できるか：できる。レシピはどれもクライアントにあるスクリプトのデータから読める。サーバーとのやり取りも、セーブデータへの書き込みも要らない
- データの量（B42.21 のゲーム本体のスクリプトを数えた）：
  - 製作のレシピ（`craftRecipe`）約970、建築の項目（`entity`）約460、料理（`evolvedrecipe`）約440、修理（`fixing`）29
  - アイテムは約1万種類あるが、検索の対象はレシピに出てくるものだけ（数千）なので、最初に一度で索引を作っても引っかかりはほぼ出ない見込み（ゲームの中で測って確かめる）
- データの読み方（ゲームの Lua で使われているもの。B42.21 で確かめた）：
  - 製作：`ScriptManager.instance:getAllCraftRecipes()`
  - 建築：`ScriptManager.instance:getAllBuildableRecipes()`（製作の一覧には入っていない。2026-11-02 に、ゲームのクラスを見て確かめた）。建築のレシピも `CraftRecipe` で、建築かどうかは `isBuildableRecipe()`、建築の分類は `getBuildCategory()`、アイコンは `getIconTexture()`
  - 建築のレシピは、アイテムではなく設置物（壁・家具・設備など）を作るので、完成品のアイテムがない
  - 材料と完成品：共通の `SurvivorComforts.forEachRecipeItem`（`Recipes.lua`）で読める。材料1つごとに：
    - 消費しない（道具）か：`isKeep()`、`isTool()`
    - 数：`getIntAmount()`。数が決まっていないもの：`isVariableAmount()`
    - なれるアイテム：`getPossibleInputItems()`（「ハンマーならどれでも」のようなタグの指定も、アイテムの一覧に直して返す）
    - 液体・エネルギー：`getResourceType()` で分かる。液体は `getPossibleInputFluids()`
  - 必要なスキル・習得・明るさ・場所：`getRequiredSkillCount()` と `getRequiredSkill()`、`needToBeLearn()`、`canBeDoneInDark()`、`isAnySurfaceCraft()`、`isCanBeDoneFromFloor()`（本体の製作の画面 `ISWidgetTitleHeader.lua` などが使うもの）
  - 料理（スープ・サラダなど）：`getEvolvedRecipes()`（`ISInventoryPaneContextMenu.lua`）
  - 修理：`FixingManager.getFixes(item)`（`ISInventoryPaneContextMenu.lua`）。アイテムの実物を渡す形なので、全部の修理の一覧を読む方法は実装のときに調べる
- HTML 版との違い：
  - ゲームが読み込んだレシピをそのまま使うので、サーバーで入れている MOD のレシピも出る。ゲームを更新しても古くならない
  - 一覧のデータ（HTML 版は 3.4MB）を MOD に入れる必要がない。最初に開いたときに一度だけ索引を作る
- 使い回せるもの：
  - 共通の検索（`Search.lua`：ひらがなとカタカナを区別しない、空白で絞り込む）と、F14 の英語名の表
  - ウィンドウの共通部品（`Window.lua`）と画面左のボタン。一覧は F06・F09 と同じ `ISScrollingListBox` を元にする
  - F12 の「作れるアイテムの一覧」と、製作の画面を開いて絞り込む処理（`Recipes.lua`）
- 難しさ：中〜高。新しいウィンドウ（検索欄・結果の一覧・詳しい表示・材料の展開）が要る。料理と修理は、データの読み方を調べるところから
- 判定：**自作**（itsu07 さんの HTML のアプリを元に、Lua で作り直して Survivor Comforts に入れる）

## 仕様

### 段階

段階を分けて作る。まず 1 を作り、2 以降は 1 を使ってみてから細かいところを決める。

1. 製作と建築の作り方と使い道
   - 建築も製作と同じレシピの一覧に入っているので、最初から「建築」と書いて一緒に出す
2. 材料の展開と、どの本で覚えるか
   - 本で覚えるレシピは、本のアイテムを全部調べる必要があるので、ここで作る
3. 料理と修理
   - 読み方が製作と違うので、最後に作る

### ファイル

- `client/SurvivorComforts/RecipeIndex.lua`：索引を作る（画面とは分ける。テスト用の MOD で確かめやすくするため）
  - アイテム（`fullType`）→ 作るレシピ、材料として消費するレシピ、道具として使うレシピ
  - 検索の対象のアイテムの一覧（どれかのレシピに出てくるもの）
  - F12 の「作れるアイテムの一覧」（`Recipes.lua` の `hasRecipe`）は、あとでこの索引に寄せて1つにする
- `client/SurvivorComforts/F16_RecipeFinder.lua`：ウィンドウと表示
- 翻訳（日本語・英語）に `F16_*` を足す

### 索引

- 最初にウィンドウを開いたときに一度だけ作る。レシピは遊んでいる間に変わらないので、作り直さない
- 目立つ引っかかりが出るなら、何回かに分けて作る
- 作れなかったとき（エラー）は、ログに出し、ウィンドウには「レシピを読めませんでした」と出す

### 画面

- 外枠は `Window.lua` で作る（F08・F09 と同じ。大きさを変えられ、位置と大きさを覚える）。最初の大きさは 1200×800（画面に収まらないときは、収まる大きさまで縮める）
- ウィンドウの名前は「アイテム検索」（アイテムから調べる画面のため。機能の名前は「レシピ検索」のまま）
- 開き方：画面左のボタンと、オプションで決めたキー（初期値はキーなし）
  - F12 の右クリック「レシピを見る」と、F06 のウィッシュリストから開けるようにするかは、段階 1 を使ってみてから決める
- 並び（HTML 版と同じ）：
  - 上：検索欄と、絞り込みの選択欄（すべて／作れる／素材（作れない））
  - 左：検索結果のアイテムの一覧（アイコンと名前）
  - 右：選んだアイテムの情報
- 右の情報は、文章の欄ではなく、1行ずつの一覧（`ISScrollingListBox` を元にする）で作る
  - いちばん上は選んだアイテムの行で、ほかの行より高くし、大きいアイコンと大きい文字の名前、その下に分類（インベントリと同じ表示）と内部名を出す
  - 行の種類：見出し（作り方・使い道）、レシピ（名前と「製作」「建築」の区別）、材料・道具、条件（スキル・習得・明るさ・場所）
  - アイテムの行をクリックすると、そのアイテムの情報に移る。「戻る」で前に戻れる
  - 段階 2 の「材料を展開」は、材料の下に字下げした行を足して作る
- 作り方：レシピごとに
  - 材料（消費）と道具（消費しない）を分けて、数と一緒に出す
  - 「ハンマーならどれでも」のように、なれるアイテムが複数ある材料は「ハンマー など5種」と1行にまとめ、クリックで全部を開く
  - 液体の材料は、名前と量の文字だけで出す
  - 必要なスキル、習得が要るか、明るさが要るか、作る場所
- 使い道（逆引き）：材料として消費するレシピと、道具として使うレシピを分けて出す
- この画面から直接は作らない。右クリックのメニューから本体の製作・建築の画面を開いて作る（2026-11-02 に決定）：
  - 左の一覧と右のアイテムの行（選んだアイテム、材料・道具・完成品）：
    - 「製作する」：製作のレシピで作れるアイテムのとき。本体の製作の画面を、そのアイテムを作るレシピに絞り込んで開く（F12 の「レシピを見る」と同じ）
    - 建築のレシピはアイテムを作らない（設置物を作る）ので、アイテムには「建築する」は出さない
  - 右のレシピの行：「[製作]」なら「製作する」、「[建築]」なら「建築する」。本体の製作・建築の画面を、そのレシピを選んだ状態で開く（本体の読書の画面と同じ `ISEntityUI.OpenHandcraftWindow`・`OpenBuildWindow`）
  - どちらも、続けてウィッシュリストの行（F06。「ウィッシュリストに追加」など）を出す。レシピの行は、その完成品のアイテムについて出す。ウィッシュリストの行は、製作・建築の画面の右クリックと共通（`CraftMenu.lua` の `fillCraftMenu`）
- 出さないもの：HTML 版の「定義の原文」（ゲームの中ではスクリプトの原文が読めないため）と、ダーク表示の切り替え（ゲームの UI の色に合わせる）

### 表記

ゲームの日本語の画面と同じ言葉にする（2026-11-02 に決定）。ゲームの翻訳のキーをそのまま使えるところは使い、ほかの言語でもゲームと同じ言葉になるようにする。

| 意味 | 表記 | ゲームの翻訳のキー |
| --- | --- | --- |
| 製作（作業台・手で作る） | 製作 | `IGUI_CraftingWindow_Craft` |
| 建築（設置物を作る） | 建築 | `IGUI_CraftingWindow_Build` |
| 使ってなくなるもの | 材料 | `IGUI_CraftingWindow_Requires` |
| できるもの | 完成品 | `IGUI_CraftingWindow_Creates` |
| なくならないもの | 道具 | ゲームの日本語の翻訳がない（英語のまま「Tools」）ので、この MOD の翻訳 |

この MOD のほかの機能の説明（オプションの画面）も「製作」「材料」にそろえる。

### 建築物

- 建築のレシピ1つを、左の一覧の1行（建築物）として出す。名前はレシピの名前、アイコンはレシピのアイコン
- 選ぶと、右にその建築物の作り方（建築のレシピ。材料・道具・条件）を出す。分類の欄には「建築」と出す
- 絞り込みに「建築物」を足す（すべて／作れるもの／素材（作れない）／建築物）
- 右クリック：「建築する」で、建築の画面をそのレシピを選んだ状態で開く。アイテムではないので、ウィッシュリストの行は出さない
- 検索は、レシピの名前で探す（F14 が ON なら英語名でも）

### 検索

- 共通の検索（`Search.lua`）を使う。ひらがなとカタカナを区別せず、空白で区切ると全部を含むものに絞り込む
- F14 を有効にしていれば、英語名でも見つかる
- 対象は、どれかのレシピの材料・道具・完成品になっているアイテムと、建築物
- 検索欄が空のときは、左の一覧に何も出さず、「名前を入れて検索してください」と出す（絞り込みを選んでいても同じ。2026-11-02 に決定）

### オプション・そのほか

- オプション：`F16_enabled`（有効にする）、`F16_key`（開くキー）。見出しは「レシピ」（F12・F03・F07 と同じ）
- セーブデータには何も書き込まない。サーバーの処理はない
- 元のアプリの作者（itsu07 さん）を README・機能の一覧・ワークショップの説明に書く。元のコードは使わない（Lua で作り直した）。公開してよいことは作者に確かめた（2026-11-02）
- 安定版の前に、アルファ版（Survivor Comforts (Alpha)、Workshop ID `3832140066`。2026-11-02 に 0.5.0-alpha.1a95f1c を公開。[dev-guide.md の「アルファ版」](../dev-guide.md#アルファ版)）で試してもらう

- [ ] 初めて開いたときの大きさが 1200×800 ほど（位置と大きさを覚えたあとは、その大きさ）
- [ ] 初めて開いたときに、目立つ引っかかり（一瞬止まる）がない

- [ ] 検索欄が空のときは、左の一覧に何も出ない。文字を消すと一覧が空に戻る

- [ ] 作り方のレシピに、材料・道具・完成品と数、条件（スキル、習得、明かり、場所）が出る
- [ ] 「[+]」の行を押すと開き、「[-]」で閉じる。「ハンマー など○種」の行を押すと、なれるアイテムが並ぶ
