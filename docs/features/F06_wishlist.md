## 仕様

- 案：アイテムを右クリックして「ウィッシュリストに追加」。そのアイテムを拾える場所で目印を出す、インベントリ画面で強調表示する
- 個人用の範囲（実装済み）：
  - インベントリ・周りの容器のアイテムを右クリックして追加・外す。リストにある種類は一覧の行を色付けする
  - 一覧のウィンドウで確認・外す。開くのは画面左のアイコンのボタン（オプションで表示・非表示）かキー。アイテムの右クリックには「開く」を出さない
  - リストは自分のPCの `Zomboid\Lua\SurvivorComforts_Wishlist.txt` にだけ保存する（ワールドには書き込まない）
- 制作・建築の画面からも追加できる
  - 材料・完成品のアイコンを右クリック：アイコンに今表示されているアイテムだけを追加・外す（代わりに使える候補すべては出さない）
  - 材料をクリックすると開く「使えるアイテムの一覧」の行を右クリック：その行のアイテムを追加・外す
  - レシピ一覧（リスト表示とアイコン表示）の行を右クリック：そのレシピの完成品を追加・外す。建築のレシピは完成品がアイテムではないので、材料の右クリックを使う
  - 本体の左クリック・Shift+クリック（絞り込み）の動作は変えない
- 画面左のアイコンのボタンは、スキルウィンドウ（F08）と共通の仕組み（`Sidebar.lua`）で並べる。非表示のボタンは隙間を空けずに詰める。画面の下から1アイコン分のところまで来たら、右に次の列を作ってアイコンの一番上から続ける
- 一覧のウィンドウで行を右クリックすると、次の2つが出る
  - 「ウィッシュリストから外す」
  - 「レシピを見る」：本体の制作の画面を開き、そのアイテムを作れるレシピに絞り込む。本体で材料を Shift+クリックしたときと同じ絞り込み（完成品の名前で検索、知らないレシピも表示）を使う。建築の画面は対象外
- 共有版（みんなのリスト）の範囲：
  - 考え方：編集するのは自分のリストだけ。自分のリストのアイテムを「共有」すると、みんなのリストに出る。みんなのリストは、誰かが共有しているアイテムを集めて見るための閲覧用
  - 操作の流れ
    1. ウィッシュリストに追加：自分のリストに入る（共有はしない）。最初から共有したいときは「追加して共有する」で、追加と共有を1回で行う（2026-10-30 追加）
    2. 共有する：自分のリストに残したまま、みんなのリストにも出る
    3. 共有を解除：自分のリストには残り、みんなのリストからは自分の分だけ外れる
    4. ウィッシュリストから削除：自分のリストから消える。共有していたら、共有も一緒に解除する
  - 同じアイテムを何人でも共有できる。サーバーはアイテムごとに「共有している人」の一覧を持ち、解除はその人の名前だけを外す。全員が外れたときに、みんなのリストから消える（ほかの人の共有を巻き込んで消さない）
  - 共有を解除できるのは、共有した本人だけ。サーバーは、コマンドを送ってきたプレイヤーの名前でだけ外す。例外として、管理者は「みんなのリストから外す」で、そのアイテムの共有を全員分まとめて外せる（やめた人の共有を片付けるため）
  - 右クリックのメニュー（インベントリ・周りの容器、制作・建築の画面、一覧のウィンドウの「自分」タブで共通）：「ウィッシュリスト」の下に、アイテムの状態に合わせて出す
    - 自分のリストにない：「ウィッシュリストに追加」「追加して共有する」
    - 自分のリストにあり、共有していない：「共有する」「ウィッシュリストから削除」
    - 自分のリストにあり、共有している：「共有を解除」「ウィッシュリストから削除」
    - 種類の違うアイテムをまとめて選んだときは、アイテム名ごとにその項目を並べる
  - 自分が共有しているアイテムは、自分のリストのファイルに無くても、自分のリストに出す（自分のリストはサーバーやセーブをまたいで同じものを使うので、別のサーバーにいる間に削除すると、前のサーバーの共有だけが残るため。そのサーバーに戻れば、削除や共有の解除ができる）
  - 色付け：自分のリストはオレンジ、みんなのリスト（ほかの人の共有を含む）は水色。両方に入っているもの（自分のリストにあり、自分かほかの人が共有している）は、赤い印1本と赤みがかった行になる
  - 一覧のウィンドウ：本体のタブ（`ISTabPanel`、キャラクター情報と同じ見た目）で「自分」「みんな」を切り替える
    - 「自分」タブ：自分が共有しているアイテムには水色の印を付ける。右クリックは上のメニューと「レシピを見る」
    - 「みんな」タブ：閲覧用。名前の後ろに共有している人を出す（2人までは「（Aさん、Bさん）」のように名前、3人以上は「（3名以上）」）。右クリックは「レシピを見る」と、自分のリストにないときは「自分のリストに追加」（共有はしない）と「追加して共有する」（自分も欲しいときに、共有している人に自分の名前が加わる）。管理者には「みんなのリストから外す」も出す
    - 下のボタン「選んだものを外す」は「自分」タブでだけ使え、「ウィッシュリストから削除」と同じ動きにする
  - オプション「みんなのリストを使う」（初期値ON）。OFFにすると、共有の項目・水色・「みんな」タブが消え、自分のリストだけの表示・メニューに戻る（サーバーにある自分の共有はそのまま残る）
  - 保存と配信はサーバー側のLua（`server/SurvivorComforts/F06_SharedWishlist.lua`）で行う
    - ワールドの Global ModData（`SurvivorComforts_SharedWishlist`）に、アイテムごとの共有している人（とその順番）を保存する。方針の例外で、MODを外してもこのデータが残るだけで害はない
    - 前の形（アイテムごとに追加した人1人）のデータは、読み込んだときに「追加した人が共有している」形に置き換える
    - クライアントからは `sendClientCommand` で「一覧をください」「共有する」「共有を解除」「（管理者）外す」を送る。サーバーは一覧が変わるたびに、全員に `sendServerCommand` で一覧を送る
    - ログインしたときに一覧を受け取る
    - サーバー側で確かめること：存在するアイテムか、リストが多すぎないか（300種類まで）、管理者の操作は送ってきた人が管理者か
    - 安全弁（荒らしや、改造したクライアントからの連打への備え。2026-10-30 追加）
      - 1人が共有できるのは30種類まで（`MAX_PER_PLAYER`）。超えた共有はサーバーが受け付けない（メニューは「共有する」のまま）。1人でみんなのリストの枠（300種類）を使い切れないようにするため
      - 1人が送れるコマンドは、1秒に5回まで。超えた分はサーバーが捨てる。ふつうの右クリックの操作では届かない回数
      - 全員への一覧の送信は、1秒に1回まで。その間の変更はまとめて、次の送信で送る（共有と解除を連打されても、送信の回数が増えない）
      - 自分のリストは100件まで（`MAX_PERSONAL`。自分が共有しているアイテムも数に入る）。自分のPCにしか保存しないのでサーバーには響かないが、色付けやウィンドウが重くならないようにする
  - いっぱいのときの表示：上限に達していたら、メニューの項目を本体と同じく赤い選べない表示にし、マウスを乗せると理由を出す（本体の `notAvailable` とツールチップ）
    - 「ウィッシュリストに追加」「自分のリストに追加」：自分のリストが100件のとき「ウィッシュリストがいっぱいです（100件まで）」
    - 「共有する」：自分が30種類共有しているとき「共有できるのは30種類までです」。みんなのリストが300種類のとき「みんなのリストがいっぱいです（300種類まで）」
    - サーバーも同じ上限で確かめるので、表示と食い違っても、上限を超えて登録されることはない
    - シングルプレイ：クライアントからの `sendClientCommand` はゲームが内部でサーバー側のLuaに渡すが、サーバーからの `sendServerCommand` は何もしない（ゲーム本体で確認）。そのため、シングルプレイのときだけ、サーバー側のLuaから `triggerEvent("OnServerCommand", ...)` で直接クライアント側に一覧を渡す

## 確認項目

### 個人用

- [ ] オプション →「MOD」に「ウィッシュリスト」が表示される
- [ ] アイテムを右クリック →「ウィッシュリストに追加」で追加できる（「ウィッシュリストを開く」は出ない）。※「みんなのリストを使う」がOFFのとき。ONのときは下の「みんなのリスト」を参照
- [ ] 追加したアイテムは、インベントリと周りの容器の一覧で、行がオレンジがかって左端に印が出る（まとまった行も、開いた中の行も）
- [ ] 同じ種類のアイテムはすべて色付きになる（別の容器にあるものも）
- [ ] もう一度右クリックすると「ウィッシュリストから外す」になり、外すと色が消える
- [ ] 種類の違うアイテムをまとめて選んで右クリックすると、「ウィッシュリスト」の下に「追加：〇〇」「外す：〇〇」が種類ごとに並び、1つずつ追加・外すができる

### 制作・建築の画面から追加する

- [ ] 制作の画面で、材料のアイコンを右クリックすると、アイコンに今表示されているアイテムだけが「ウィッシュリストに追加」の対象になる（候補が切り替わる材料は、右クリックした時に出ていたもの）
- [ ] 完成品のアイコンを右クリックして追加できる
- [ ] 材料をクリックして出る「使えるアイテムの一覧」で、行を右クリックするとそのアイテムを追加できる（持っていないアイテムの行も）。見出しの行では何も出ない
- [ ] 左のレシピ一覧（リスト表示・アイコン表示の両方）でレシピを右クリックすると、完成品を追加できる。カテゴリの見出しを右クリックしても何も出ない
- [ ] 建築の画面で、材料のアイコンを右クリックして追加できる
- [ ] 追加済みのものは「外す」になり、外せる
- [ ] 1回の右クリックでメニューが1つだけ出る（二重に出ない）
- [ ] 本体の左クリック（材料の選択）と Shift+クリック（絞り込み）が今まで通り動く
- [ ] 液体（水など）の材料を右クリックしても何も出ない

### 一覧のウィンドウ

- [ ] 画面左のアイコンに星のボタンが出て（スキルのボタンの下）、マウスを乗せると「ウィッシュリスト」と出る。クリックで一覧が開閉し、開いている間は色付きになる
- [ ] 設定「左のアイコンにボタンを表示する」をOFFにするとボタンが消え、隙間が詰まる。スキルのボタンだけOFFにしても、星のボタンが上に詰まる
- [ ] 一覧にアイコンと名前が並ぶ。空のときは案内が出る
- [ ] 一覧で選んで「選んだものを外す」で外せる。ウィンドウを開いたまま右クリックで追加しても、一覧がすぐ更新される
- [ ] 一覧の行を右クリックすると「レシピを見る」「ウィッシュリストから外す」が出る（空いている所では何も出ない）
- [ ] 「レシピを見る」で制作の画面が開き、そのアイテムを作れるレシピだけに絞り込まれる。制作の画面が開いているときは、そのまま絞り込みが変わる
- [ ] 作るレシピがないアイテム（缶詰など）では「レシピを見る」が選べない表示になる
- [ ] オプションでキーを決めると、そのキーで一覧が開閉する（初期値はキーなし）
- [ ] ゲームを終了して再開しても、リストが残っている（`%USERPROFILE%\Zomboid\Lua\SurvivorComforts_Wishlist.txt`）
- [ ] 「有効にする」を外すと、色付けと右クリックの項目が消える
- [ ] マルチプレイ（ローカルで立てたサーバー）でも同じように動く

### みんなのリスト（共有版）

- [ ] オプションに「みんなのリストを使う」が出る（初期値ON）
- [ ] 自分のリストにないアイテムを右クリックすると「ウィッシュリスト」→「ウィッシュリストに追加」「追加して共有する」が出る。「ウィッシュリストに追加」は自分のリスト（オレンジ）にだけ入る

- [ ] 「共有する」と、みんなのリストに出て、インベントリの左端の印と行の色が赤になる。メニューは「共有を解除」に変わる

- [ ] 種類の違うアイテムをまとめて選ぶと、「ウィッシュリスト」→ アイテム名 → その項目、と並ぶ
- [ ] 制作・建築の画面と、一覧のウィンドウの「自分」タブの右クリックでも、同じ項目が出る（「自分」タブには「レシピを見る」も出る）

- [ ] 「みんな」タブの右クリックには「レシピを見る」と、自分のリストにないときだけ「自分のリストに追加」が出る。「外す」は出ず、「選んだものを外す」のボタンは押せない
- [ ] 「みんな」タブから「自分のリストに追加」すると、自分のリストに入る（共有はされない）
- [ ] 「みんな」タブから「追加して共有する」を選ぶと、自分のリストに入り、そのアイテムの共有している人に自分の名前が加わる
- [ ] 管理者には「みんな」タブの右クリックに「みんなのリストから外す（管理者）」が出て、選ぶと全員分の共有が消える。管理者でない人には出ない
- [ ] もう1人が共有・解除すると、自分の一覧と色付けがすぐ変わる
- [ ] ログインし直しても、サーバーを再起動しても、みんなのリストと共有している人が残っている
- [ ] 前の版で追加したみんなのリストのアイテムは、追加した人が共有している形で残っている
- [ ] 自分のリストのファイル（`Zomboid\Lua\SurvivorComforts_Wishlist.txt`）から共有中のアイテムを消してログインし直しても、そのアイテムは「自分」タブに出て、解除・削除できる
- [ ] シングルプレイでも、共有・解除ができ、保存して再開しても残っている
- [ ] 「みんなのリストを使う」をOFFにすると、共有の項目・水色・「みんな」タブが消え、自分のリストだけの表示に戻る
- [ ] サーバーのログに `[SurvivorComforts] F06 server` のエラーが出ていない

### 安全弁

- [ ] 1人で30種類共有すると、ほかのアイテムの「共有する」が赤く選べなくなり、マウスを乗せると「共有できるのは30種類までです」と出る。1つ解除すると、また選べる。ほかの人はそのあとも共有できる
- [ ] 自分のリストが100件になると、「ウィッシュリストに追加」（インベントリ、制作・建築の画面、「みんな」タブの「自分のリストに追加」、まとめて選んだときの「追加：〇〇」）が赤く選べなくなり、「ウィッシュリストがいっぱいです（100件まで）」と出る。1件削除すると、また追加できる
- [ ] 「みんなのリストを使う」がOFFのときも、100件で追加が赤くなる
- [ ] 試すときは、`Zomboid\Lua\SurvivorComforts_Wishlist.txt`（テスト用のゲームなら `%USERPROFILE%\PZTest\client1\Lua\`）に、1行に1つアイテムの種類（`Base.Nails` など）を並べて100件にしておくと早い
- [ ] 右クリックで続けて共有・解除しても、取りこぼさず全部反映される（ふつうの操作で回数の制限にかからない）
- [ ] 共有・解除を続けて行っても、もう1人の画面には遅くとも数秒で反映される（全員への送信をまとめている）
