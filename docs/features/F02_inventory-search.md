# F02 インベントリ検索

- 状況：⬜ 未実装（作者からソースコードが届いてから同梱する）
- 一覧に戻る：[features.md](../features.md)

## 要望

- 内容： インベントリにあるアイテムをテキストで検索できるようにする
- 困っている場面・理由： 大量のアイテムがある場合、インベントリから目当てのアイテムを探すのが面倒
- 優先度：　高
- 対応済み、個別のMODでほかの人が実装済み
- ソースコードを共有してもらいパッケージに同梱する

## 調査結果

- 既存MOD：ほかの人が作った個別のMODがある（ソースコードを共有してもらう予定）。参考：Better Containers（3586216562）にも検索機能がある
- B42.21のMPで動くか：未確認
- クライアントだけで実現できるか：できる（インベントリ画面の表示だけの話）
- 難しさ：低（同梱するだけ）
- 判定：**同梱**
- 注意：[F01](F01_japanese-input.md) と同じく、作者から許可をもらい、クレジットを載せる
- 検索との共通化（2026-10-30）：検索の決まり（語の区切り方、英語名・日本語名の両方で探す、合うかどうか）は、[F14](F14_english-search.md) で作った共通の `Search.lua` を使う予定。英語名での検索を含めるかどうかは、F14 のオプション「英語名でも検索する」にそろえる
  - 受け取ったコードの検索部分を `Search.lua` に差し替えるなら、作者のコードを書き換えることになるので、許可をもらうときにそこまで含めて確認する
  - または、`Search.lua` を使って自分たちで作る（インベントリに検索欄を足し、合わないアイテムを隠す）。どちらにするかは、F02 に取りかかるときに決める
