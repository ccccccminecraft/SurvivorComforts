### 受け取ったコード（2026-11-01）

- リポジトリ：`itsu07/pz-inventory-search`。ライセンスは MIT（著作権表示とライセンスの文を残せば、改造して同梱してよい）
- 中身
  - `InventorySearch/`：本体の MOD（Lua 1ファイル、翻訳、`mod.info`）
  - `InventorySearchClient/`：サーバーの MOD 一覧に入っていないときに、自分の PC だけで読み込むための補助の Java MOD（ZombieBuddy 前提）
  - `deploy.bat`、README など
- 作り
  - 一覧の見出し（「種類」の左）に虫眼鏡のボタンを足し、押すとタイトル帯の下に検索欄が出る。入力するたびに、名前で一覧を絞り込む
  - 本体の関数は置き換えず、元の処理を呼んでから足している（`ISInventoryPane` の `createChildren`・`refreshContainer`・列の幅を変えたとき、`ISInventoryPage` の `createChildren`・`update`）
  - 絞り込みは、本体が作った行の一覧（`itemslist`）から合わない行を除くだけ。選択中の行は、絞り込みの後に選び直す
  - コンテナを切り替えても検索の文字は残り、切り替え先にも同じ絞り込みがかかる
  - 検索の決まり：小文字にして、ひらがなをカタカナに寄せ、入力全体がアイテム名のどこかに入っていれば合う
  - ゲームの Lua（Kahlua）の注意（作者のメモ）：ソースに日本語の文字列を直接書くと壊れる。パターンを使う文字列の関数（`gsub`・`find`・`match`・`gmatch`）は、日本語を含む文字列で正しく動かない。そのため、日本語の文字は文字コードから組み立て、文字列は1文字ずつ取り出して比べている
  - 虫眼鏡の絵は、ゲーム本体の `media/ui/Search_Icon_Off.png`・`Search_Icon_On.png` を使っている（MOD に絵は入っていない）
  - 独自のオプション「デバッグログを出力する」（検索の内容を `console.txt` に記録）と、起動時の自己診断（ひらがな→カタカナが効くか）がある
  - ワールドには何も書き込まない

## 仕様

- 受け取ったコードを、この MOD の1機能として取り込む（2026-11-01 決定）
  - 補助の Java MOD（`InventorySearchClient`）は同梱しない。この MOD はサーバーの MOD 一覧に入れて使うので不要。Java の MOD はこの MOD の方針にも合わない
  - 「デバッグログを出力する」は外す。ほかの機能と同じく、エラーだけをログに出す
  - この MOD の決まりに合わせる：「オプション」→「MOD」→「Survivor Comforts」の「有効にする」で ON/OFF（初期値ON）、追加した処理は `safeCall` で囲む、翻訳キーは `UI_SurvivorComforts_F02_` で始める、グローバル変数を作らない
  - 「有効にする」を OFF にすると、虫眼鏡のボタンと検索欄が消え、絞り込みも外れる
- 検索の決まりは、共通の `Search.lua` に合わせる（2026-11-01 決定）
  - 空白（全角の空白も）で区切った語が、すべて名前に入っていれば合う。大文字・小文字は区別しない
  - ひらがなとカタカナを区別しない。作者のコードの処理を `Search.lua` に取り込み、F14 の検索にも効かせる
  - F14 のオプション「英語名でも検索する」が ON で、ゲームの言語が英語でないときは、英語名と内部名の単語でも当たる（例：日本語でプレイしていても `hammer` で金槌が見つかる）
  - 比べる名前は、一覧に出ている名前（`InventoryItem:getName(player)`）。同じ種類でも、名前を付けたものなどは名前が違うので、名前ごとに作る
  - 日本語を含む文字列にパターンを使う関数を使わない（作者の注意に合わせ、`Search.lua` の語の区切りも1文字ずつに直す）
- 検索の対象は、各画面に出ている行の名前だけ。バッグの中身は探さない
- ゲームパッドは対象外

### 動作確認の後に足したこと（2026-11-01）

- 検索欄は、最初は閉じておく（元のコードと同じ）。一度は最初から開いておく形にしたが、やめた（2026-11-01）
- 合わないアイテムの見せ方を、オプション「合わないアイテムも半透明で表示する」（初期値ON）で選ぶ
  - ON：合うアイテムを一覧の上にまとめ、合わないアイテムはその下に、暗くして（半透明に見えるように）表示する。合う・合わないそれぞれの中の並びは、本体の並べ方のまま
  - OFF：合わないアイテムを一覧から隠す（元のコードの動き）
- 「すべて取る」「すべて移す」は、検索の文字が入っている間は、検索に合うアイテムだけを移す。文字が空のとき、検索欄を閉じているとき、機能が OFF のときは、本体の動きのまま（コンテナ全体）
  - 本体は、コンテナの中身から移すものを選んで `transferItemsByWeight` に渡している。「すべて取る」（`lootAll`）・「すべて移す」（`transferAll`）の間だけ、そこに渡されたものから合わないアイテムを除く
  - 「すべて捨てる」（ゴミ箱を空にする）は対象外。本体のまま
- クレジット：README の機能の一覧と「ライセンス」に、元の MOD と作者を書く。`LICENSE` に作者の著作権表示を足す
