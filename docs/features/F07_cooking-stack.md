# F07 料理で同じ種類の食材をまとめる

- 状況：✅ 実装済
- コード：`client/SurvivorComforts/F07_CookingStack.lua`
- 一覧に戻る：[features.md](../features.md)

## 要望

最初の名前：料理で同種の食材をスタックさせる

- 内容：　 料理で同種の食材が複数表示されていてやりづらいので、同種の食材調味料はスタックして残量が少ないものから使う
- 困っている場面・理由: 料理で同種の食材が複数表示されていてやりづらい
- 優先度: 高

## 調査結果

- 既存MOD：Project Cook [B42]（3490188370）：料理専用の画面。まとめる機能があるかは未確認
- B42.21のMPで動くか：未確認
- クライアントだけで実現できるか：できる。食材を追加する右クリックメニュー（`ISInventoryPaneContextMenu.doEvorecipeMenu`）は、同じ種類で使用量も同じ食材しかまとめておらず、調味料はまとめていなかった。同じ種類を1行にまとめ、残量が一番少ないものを選んで追加する。実際に追加する処理（`ISAddItemInRecipe`）は本体のものをそのまま使う
- 難しさ：低〜中
- 判定：**自作**

## 仕組み

- メニューは本体の関数（`doEvorecipeMenu`）にそのまま作らせる。ほかの MOD がこの関数に加えた変更や、ゲームの更新での変更も、そのまま効く（2026-10-30 の点検の R5-2。最初は本体の関数を丸ごと置き換えていた）
- 本体の関数が動いている間だけ、メニューに食材を1行足す関数（`addItemInEvoRecipe`）に割り込み、終わったら元に戻す
  - 同じ種類（名前・凍っている・腐っている・調理済みなどが同じ）の2つめ以降は、行を足さない
  - 最初の1行は、残りが一番少ないものに入れ替え、「（3個）」のように数を付けてから、元の関数で足す
- 数と「残りが一番少ないもの」は、使える食材の一覧（`getItemsCanBeUse`）を F07 も取り出して数える。本体は種類と使用量が同じ食材を先に間引いているので、本体から届く行だけでは数がずれるため
- 割り込みの中でエラーが出たら、その行は本体のまま足す。メニュー作りでエラーが出ても、割り込みは必ず元に戻す

## 確認項目

準備：鍋の水（スープ）やボウル（サラダ）などと、同じ食材を複数（食べかけを含む）、塩などの調味料を複数持っておく。

- [ ] オプション →「MOD」に「料理の食材をまとめる」が表示される
- [ ] 鍋などを右クリック →「スープ」などの中で、同じ食材が1行にまとまり、「（3個）」のように数が出る
- [ ] 調味料（塩、コショウなど）も1行にまとまる
- [ ] 選ぶと、食べかけなど残りが一番少ないものが使われる（何度か続けて加えて確かめる）
- [ ] 腐った食材・凍った食材・調理済みの食材は、普通の食材とは別の行になる
- [ ] 凍っていて加えられない食材は、本体と同じく選べない表示（理由のツールチップ付き）になる
- [ ] 床や棚の容器にある食材も、本体と同じく一覧に出て、選ぶと取ってきて加える
- [ ] 「ランダムに加える」（食材の種類ごと）は本体と同じように出る
- [ ] 「有効にする」を外すと、本体と同じ一覧に戻る
- [ ] マルチプレイ（ローカルで立てたサーバー）でも同じように動く
