# F07 料理で同じ種類の食材をまとめる

- 状況：✅ 実装済
- コード：`client/SurvivorComforts/F07_CookingStack.lua`
- 一覧に戻る：[features.md](../features.md)

## 要望

最初の名前：料理で同種の食材をスタックさせる

- 内容：　 料理で同種の食材が複数表示されていてやりづらいので、同種の食材調味料はスタックして残量が少ないものから使う
- 困っている場面・理由: 料理で同種の食材が複数表示されていてやりづらい
- 優先度: 高

## 調査結果

- 既存MOD：Project Cook [B42]（3490188370）：料理専用の画面。まとめる機能があるかは未確認
- B42.21のMPで動くか：未確認
- クライアントだけで実現できるか：できる。食材を追加する右クリックメニュー（`ISInventoryPaneContextMenu.doEvorecipeMenu`）は、同じ種類で使用量も同じ食材しかまとめておらず、調味料はまとめていなかった。このメニューの作り方を変え、同じ種類を1行にまとめ、残量が一番少ないものを選んで追加する。実際に追加する処理（`ISAddItemInRecipe`）は本体のものをそのまま使う
- 難しさ：低〜中
- 判定：**自作**

## 確認項目

準備：鍋の水（スープ）やボウル（サラダ）などと、同じ食材を複数（食べかけを含む）、塩などの調味料を複数持っておく。

- [ ] オプション →「MOD」に「料理の食材をまとめる」が表示される
- [ ] 鍋などを右クリック →「スープ」などの中で、同じ食材が1行にまとまり、「（3個）」のように数が出る
- [ ] 調味料（塩、コショウなど）も1行にまとまる
- [ ] 選ぶと、食べかけなど残りが一番少ないものが使われる（何度か続けて加えて確かめる）
- [ ] 腐った食材・凍った食材・調理済みの食材は、普通の食材とは別の行になる
- [ ] 凍っていて加えられない食材は、本体と同じく選べない表示（理由のツールチップ付き）になる
- [ ] 床や棚の容器にある食材も、本体と同じく一覧に出て、選ぶと取ってきて加える
- [ ] 「ランダムに加える」（食材の種類ごと）は本体と同じように出る
- [ ] 「有効にする」を外すと、本体と同じ一覧に戻る
- [ ] マルチプレイ（ローカルで立てたサーバー）でも同じように動く
