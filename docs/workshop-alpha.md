# ワークショップのページ（アルファ版）

- [README に戻る](../README.md)

アルファ版「Survivor Comforts (Alpha)」のワークショップのページに載せる文です。

- ページ：https://steamcommunity.com/sharedfiles/filedetails/?id=3832140066（Workshop ID `3832140066`、MOD ID `SurvivorComfortsAlpha`、未掲載）

アルファ版の決まりとアップロードの手順は [dev-guide.md の「アルファ版」](dev-guide.md#アルファ版) にあります。

- 初めて `tools\deploy.ps1 -Alpha` を実行したときに、下の「説明」のコードブロックから `workshop.txt` を作ります（`workshop.txt` がまだないときだけ）。アップロードしたあとに説明を変えるときは、Steam のページで直すか、`%USERPROFILE%\PZDev\Workshop\SurvivorComfortsAlpha\workshop.txt` の `description=` の行を直します
- 説明は 8000 バイトまでです（日本語は1文字3バイト）

## 説明

```
[h1]Survivor Comforts (Alpha)[/h1]
Survivor Comforts の開発中の版です。次の版に入れる予定の機能を、先に試したい人のための版です。
安定版：https://steamcommunity.com/sharedfiles/filedetails/?id=3829529741

[h2]注意[/h2]
[list]
[*]安定版の Survivor Comforts と同時に有効にしないでください。どちらか片方だけを使います
[*]マルチプレイでは、サーバーに入っている方が使われます。アルファ版を試すときは、シングルプレイか、アルファ版を入れたサーバーで遊んでください
[*]開発中なので、動きが変わったり、不具合があったりします
[*]オプションの設定は、安定版と共通です
[/list]

[h2]安定版にない機能[/h2]
[list]
[*]F16 レシピ検索：アイテムや建築物の名前で検索して、作り方（製作・建築・料理）と直し方、材料・道具としての使い道を調べるウィンドウ。材料の作り方をその場でたどったり、今の持ち物で作れるものに絞ったりできます。右クリックで製作・建築の画面を開いたり、ウィッシュリストに追加したりできます。itsu07 さんの HTML のアプリ「PZ レシピ検索」を元に、Lua で作り直したものです
[/list]

ほかの機能は安定版と同じです。機能の一覧は安定版のページを見てください。
```

## 更新内容

アップロードするときの「変更履歴の編集」に貼る文です。

### 材料の展開・料理と修理（0.5.0-alpha.f578e16、2026-11-05 公開）

```
アイテム検索（F16）に機能を追加。
- 材料の「[+]」で、その材料の作り方をその場でたどれるようにした（「道具も展開」で道具も）
- 持っているもの・今作れるものを先に並べるようにした
- 料理（スープ・サラダなど）と修理を追加。絞り込みに「料理」「修理」を追加
- オプション「隠しレシピを表示する」を追加（初めは OFF）
- 検索欄が空のときは、絞り込みの中を全部出すようにした
- 持ち物が変わったときの調べ直しを軽くした
```

### F16 の調整（0.5.0-alpha.145ba5d、2026-11-02 公開）

```
アイテム検索（F16）の調整。
- 検索欄が空のときは、候補を出さないようにした
- 「戻る」に加えて「進む」を追加し、2つのボタンを右側の上に移した
- 絞り込みを「すべて／製作／建築／作成不可」にした
- 「作成可」のチェックボックスを追加。今の持ち物と周りの容器で作れるものを上に出す（作れないものは暗く表示。オプションで隠すこともできる）
```

```
アルファ版の最初の公開。F16 レシピ検索（アイテム検索のウィンドウ）を追加。
```
