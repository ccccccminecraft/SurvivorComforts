# Survivor Comforts

Project Zomboid（Build 42.21 以降）用の MOD です。身内のマルチプレイサーバーで使う、ちょっとした便利機能をまとめています。

- Steam ワークショップ（限定公開）：https://steamcommunity.com/sharedfiles/filedetails/?id=3829529741
- Workshop ID：`3829529741` / MOD ID：`SurvivorComforts`

- 1つの MOD に複数の機能が入っていて、機能ごとに「オプション」→「MOD」→「Survivor Comforts」で ON/OFF できます
- 新しいアイテム・レシピ・ゲームのルールは追加しません（ゲームバランスを変えません）
- 基本的にワールド（セーブデータ）には書き込みません。例外は「みんなのウィッシュリスト」と、プレイヤー一覧の最終ログインだけで、MOD を外してもデータが残るだけで害はありません

## 機能

| ID | 機能 | 内容 |
| --- | --- | --- |
| F03 | 材料のレシピをたどる | 制作・建築の画面で材料を右クリック →「レシピを見る」で、その材料を作れるレシピに絞り込みます。検索欄の左の「戻る」で、たどる前の表示に戻れます |
| F04 | 読書の残り時間 | 本を読んでいる間、読み終わるまでの時間（ゲーム内はオレンジ、現実は緑）をキャラクターの足元に表示します |
| F06 | ウィッシュリスト | 欲しいアイテムを登録すると、インベントリや周りの容器で色付きで表示されます。自分だけのリストと、サーバー全員で共有する「みんなのリスト」があります。制作・建築の画面からも追加できます |
| F07 | 料理の食材をまとめる | スープやサラダに食材を加えるメニューで、同じ食材を1行にまとめ、残りが少ないものから使います |
| F08 | スキルウィンドウ | スキルの一覧を、大きさを変えられる独立したウィンドウで表示します。画面左のボタンか、オプションで決めたキー（初期値はキーなし）で開きます |
| F09 | プレイヤー一覧 | サーバーにオンラインの人と、7日以内に来ていたオフラインの人（「3時間前」のように最終ログイン付き）を一覧で表示します。画面左のボタンで開きます。マルチプレイのみ |
| F10 | PvP の切り替えボタンを隠す | 画面左のドクロのボタンを隠し、PvP を常にオフにします |
| F12 | アイテムからレシピを見る | アイテムを右クリック →「レシピを見る」で、そのアイテムを作れるレシピに絞り込んだ制作の画面を開きます |
| F13 | ユーザーパネルのボタンを隠す | 画面左のユーザーパネル（派閥・セーフハウスなど）のボタンを隠し、下のボタンを詰めます。管理者には常に表示します。派閥などの機能は使えます |
| F14 | 英語名でも検索する | 日本語でプレイしていても、制作・建築の画面の検索で英語名（`plank` など）でもレシピが見つかります。オプションで、英語名を含めるかを選べます |

予定している機能や、作らないことにした機能は [docs/features.md](docs/features.md) にまとめています。機能ごとの詳しい仕様は [docs/features/](docs/features/) にあります。

## 導入

### サーバーで使う

[Steam ワークショップ](https://steamcommunity.com/sharedfiles/filedetails/?id=3829529741)に限定公開（未掲載）でアップロードしています。検索には出ないので、上の URL から開いてください。

サーバーの設定（`<サーバー名>.ini`）に次の2つを追加します。ほかの MOD がある場合は `;` で区切って並べます。

```
WorkshopItems=3829529741
Mods=SurvivorComforts
```

- ゲーム内のサーバー設定の画面の「Steam ワークショップ」「MOD」から選んでも同じです
- サーバー側の処理（みんなのウィッシュリスト、プレイヤー一覧）も同じ MOD に入っているので、追加の導入作業はありません
- プレイヤーは、サーバーに接続すると自動でダウンロードされます。自分でサブスクライブする必要はありません

### 一人で遊ぶ

[ワークショップのページ](https://steamcommunity.com/sharedfiles/filedetails/?id=3829529741)でサブスクライブし、メインメニュー →「MOD」で **Survivor Comforts** を有効にします。

### 手元で試す（開発用）

1. JDK（13 以降）を入れておきます（構文チェックに使います）
2. 構文チェックをして、ゲームから読める場所（`%USERPROFILE%\Zomboid\Workshop\SurvivorComforts`）へコピーします
   ```
   powershell -File tools\check.ps1
   powershell -File tools\deploy.ps1
   ```
3. ゲームのメインメニュー →「MOD」で **Survivor Comforts** を有効にします

詳しい手順は [docs/dev-guide.md](docs/dev-guide.md)、機能ごとの確認項目は [docs/features/](docs/features/) の各ファイルにあります。
